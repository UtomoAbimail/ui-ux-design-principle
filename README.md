# ui-ux-design-principle

by Utomo Abimail

A Claude Code skill with UI/UX design guidelines based on Figma's article "Seven essential UI design principles":
hierarchy, progressive disclosure, consistency, contrast, accessibility, proximity, and alignment.
It also covers interaction feedback and a checklist for verifying finished UI.

## Install

Copy `SKILL.md` into your Claude Code skills folder:

```
~/.claude/skills/ui-ux-design-principle/SKILL.md
```

Or clone it there directly:

```bash
git clone <repo-url> ~/.claude/skills/ui-ux-design-principle
```

## Use

- Type `/ui-ux-design-principle` in Claude Code to load it manually.
- Claude also loads it on its own when building, designing, reviewing, or polishing UI.
